CLDI: Collapse–Language Divergence Index

CLDI is a universal diagnostic framework for detecting symbolic system decay across domains—ancient scripts, AI model outputs, and bureaucratic workflows. It identifies when structural form persists without semantic function, revealing drift, redundancy, and recursive collapse.

This project includes:

📊 A 5-dimension scoring rubric (Legibility, Redundancy, Toolcare, Simplification, Anchoring)

🧠 Cross-domain application: archaeology (e.g. Linear A), AI model collapse, institutional ossification

📈 Visual scoring prototypes and forensic overlays

📎 Patent-ready specification for CLDI as a forensic tool
